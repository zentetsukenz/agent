# Skills

Reusable judgment patterns, organized into six lifecycle buckets. Each skill lives at
`<bucket>/<slug>/SKILL.md` with YAML frontmatter. See [SPEC.md](../SPEC.md) for
conformance rules.

| Bucket | Purpose |
|---|---|
| [discovery](discovery/index.md) | Explore a problem space before committing. |
| [planning](planning/index.md) | Design and decompose work before implementation. |
| [implementation](implementation/index.md) | Build, debug, and refactor. |
| [verification](verification/index.md) | Validate, test, and review. |
| [preservation](preservation/index.md) | Hand off, document, and maintain knowledge. |
| [meta](meta/index.md) | Shared primitives used by skills in other buckets. |
