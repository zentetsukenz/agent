# Design skills

Shape the solution before planning decomposes it. These skills establish the ubiquitous language, design module interfaces, and surface architectural friction — the work a product owner or designer does after Discovery and before a plan is drawn.

| Skill | Description |
|---|---|
| [codebase-design](codebase-design/SKILL.md) | Shared vocabulary and principles for designing deep modules — the glossary (module, interface, seam, adapter, leverage, locality), the deletion test, and testability principles other design skills build on. |
| [domain-model](domain-model/SKILL.md) | Build and sharpen the ubiquitous language — challenge fuzzy terms against concrete scenarios, keep the glossary current, and record decisions as ADRs. The active model-maintenance discipline that grilling and architecture skills call into. |
| [design-an-interface](design-an-interface/SKILL.md) | Generate multiple radically different interface designs for a module using parallel sub-agents, then compare on depth. |
| [improve-codebase-architecture](improve-codebase-architecture/SKILL.md) | Interrogate a codebase against its domain language and ADRs to surface deepening opportunities, present them as a visual HTML report, then grill through whichever one you pick. |
