- 2026-07-31 — ADR-012 (Invocation surface is a role facet) accepted; names a closed `front-door | dispatched` vocabulary parallel to the capability set (ADR-006) — stage agents are `front-door` (`user-invocable:true` + `disable-model-invocation:true`; human/handoff-entered, not subagent-pulled), all utilities are `dispatched` (`user-invocable:false`; picker-hidden, dispatcher-only); adapter maps each surface to the Mirai flag pair; extends [role-scoped-capabilities](../patterns/role-scoped-capabilities.md), adds the **Invocation surface** glossary term, parametrizes `role.agent.md.template`, and leaves an autopilot forward-pointer (handoff `send:true` = a separate future effort)
- 2026-07-31 — ADR-013 (Shared adapter-contract core) accepted; records the #7 interface design and extends ADR-005 by defining the setup contract's shared body — a **prose contract of named port-obligations** (Design B) chosen over a filled-in template pack (Design A) because templates are harness detail the SPEC forbids in shared docs; core lives in a **new top-level `contract/`** dir (not under `adapters/`, not in `workflows/`) with `index.md` + `PORTS.md`; PROVIDES the generic content (5-step contract, init/update, 6 primitives + rosters/capability-sets/interview questions/invariant-checks), an adapter MUST SUPPLY **four named obligations** (`capability→tool`, `archetype→model`, `seam-obligation→wiring` + a `primitive→file` manifest) as prose tables; consumption = **reference, never copy** (setup.md goes thin); `SETUP.md` gains a Step-2 pointer and SPEC conformance gains one bullet; design-only — the migration is the foundation-build ticket (#9)
- 2026-07-31 — ADR-014 (loom setup approach for the OpenCode harness, opt-in OMO layer) accepted; loom's **second** adapter, proving the `contract/` seam real. A thin rendering layer that references `contract/` and answers the four ports for OpenCode: `capability→tool` = `permission:` key with **`deny` as the withhold** (inverse of Mirai's omit-the-alias) and `interview` = the native `question` tool; `archetype→model` = inline `model: provider/model-id` **or** an opt-in `omo.json`; `seam-obligation→wiring` = a **committed `.loom/handoffs/` ledger** + `opencode.json` `instructions:` pointer + human `Tab`-selected transition (no memory tool, no `handoffs:` primitive — both GAPs render to the committed folder, with a scoped-edit glob so PRODUCE/DISCOVER roles write only the ledger); `primitive→file` = skills→`.opencode/skills/`, stage agents→`mode:primary`, utilities→`mode:subagent`, quick combos→`.opencode/commands/`, base agents `plan`/`build`. OMO is **strictly opt-in**; adds `wiki/environments/opencode.md`, the `adapters/opencode/` tree, the SETUP.md harness row, the SPEC OpenCode delivery-conformance section, and `validate_opencode_config` in `validate.sh`. *(Amended 2026-08-17 by ADR-021: the opt-in OMO layer is **dropped** — `archetype→model` is inline `model:` only; `references/omo.md` deleted.)*
- 2026-08-03 — ADR-015 (Communication-line refinement) accepted; amends ADR-011 by framing context-passing as **three named lanes over one ledger home**: renames the `handoff` skill → **`stage-handoff`** (keeping *stage* a runtime parameter — rejects a per-seam `handoff-planning`/`handoff-closing` split as re-shallowing the deep module), reframes `checkpoint` as selective **decision→result journalling into the memory system** (within-session, for `quick`/`deep` utility agents), and evolves `dispatch-context` by dropping obsolete subagent-invocation mechanics and adding an **unregistered `working/` within-stage lane** in the ledger namespace (only cross-stage seam artifacts stay manifest-registered; within-stage work promotes via `stage-handoff`); protocol substrate, manifest, and adapters (`.loom/handoffs/`, Mirai `handoffs:` primitive, `handoff.instructions.md`) are unchanged — only skill references repoint to `stage-handoff`; updates [seam-artifact-protocol](../patterns/seam-artifact-protocol.md)
- 2026-08-03 — ADR-016 (Embedded review gate + commit-often) accepted; rejects porting upstream `code-review` and `implement` as standalone skills — instead **embeds two-axis review (Standards + Spec) as a first-class SDLC quality gate** (Verify → Review → Commit) that [Planning](../../workflows/sdlc/planning.md) sequences as a **review-gate cadence** (one gate per tracer-bullet slice), [Implementation](../../workflows/sdlc/implementation.md) executes at Phase 5 with the Orchestrator holding the gate before advancing, and [Verification](../../workflows/sdlc/verification.md) closes as the final gate over already-reviewed slice commits; adds the cross-cutting [commit-often](../principles/commit-often.md) principle (every green gate is a commit point → small, reversible, bisectable history); the Standards axis carries a Fowler code-smell baseline the repo's documented standards override; **adopts `resolving-merge-conflicts` standalone** (a commit at a gate can hit a merge/rebase conflict) and **skips `ask-matt`** (index/bucket disclosure already routes); workflow + principle refinement only — no protocol/adapter change
- 2026-08-12 — ADR-018 (Macro project-management as a recursive wayfinding layer over SDLC) accepted; rejects both embedding macro PM in SDLC and adding a peer `workflows/pm/` — macro PM is a **continuous, recursive decomposition** (Vision→Milestone→Epic as nested `wayfinder:map`s, "Sprint" as a time-box dropped in favour of the frontier) whose **leaves are SDLC runs**, and it reuses [wayfinder](../../SKILLS/planning/wayfinder/SKILL.md) rather than a new skill; the **tracker is the single source of truth** and the resident agent is a **reactive worker** whose private memory holds only continuity/persona/skills, never project state; generalizes the seam protocol's "substrate is a choice" to **altitude-scoped** (macro = a networked/external store — a **third substrate class** the protocol lacked, since memory doesn't distribute and a committed folder pollutes the code tree; micro = harness memory); the **altitude seam is a translator** (board ticket ⇄ SDLC memory ledger) reusing the existing PRODUCE/DISCOVER contract; a **mechanical, table-driven router** (restart-safe → keeps the board authoritative) reads a **two-vocabulary label protocol** — `wayfinder:*` **down** (reuse the four types; `task`+execution-override = buildable leaf) and `sdlc:*` **up** (an evolving status mirroring the HITL/AFK split — AFK returns like `sdlc:needs-recharter` the router handles, HITL returns like `sdlc:needs-clarification` fold back into a `wayfinder:grilling` ticket); **right-sizing is a boundary rejection** at Planning's DISCOVER gate (no predictive sizer — Planning only reports `sdlc:needs-recharter`, the router graduates the leaf to a sub-map); the **source of truth is a user choice** at `init`/`update` (default networked board, any tool the setup agent gauges the fit for) named in the [communication protocol document](../patterns/seam-artifact-protocol.md#4-the-communication-protocol-document), guarded by a **substrate-agnostic one-source-of-truth invariant** (a second unregistered tracker is the violation, not the substrate choice); **protocol lands in loom core** (extend wayfinder + comm-protocol doc + `contract/` interview) while the **resident 24/7 daemon is a later adapter port** (e.g. `adapters/hermes/`), keeping [ADR-005](adr-005-harness-agnostic-setup.md)'s harness-agnostic stance; design/decision only — the wayfinder extension, protocol third-substrate, and contract interview are follow-on build tickets
- 2026-08-03 — ADR-017 (Quality baseline embedded in setup and every gate) accepted; introduces a per-project **quality baseline** across four aspects (lint, code-quality, security, coverage) chosen during the setup **interview** (new §4e) from **keyless-first** tools per detected stack, with a **ratchet/no-regression** floor by default (optional absolute target) and a **single source of truth** (project committed config preferred, provenance-marked project-context section as fallback); enforced **prose-first** at the *existing* [quality gate](../../workflows/sdlc/implementation.md#quality-gates)'s Verify step ([Planning](../../workflows/sdlc/planning.md) names each gate's aspects, [Implementation](../../workflows/sdlc/implementation.md) runs them per slice with the Orchestrator holding on breach, [Verification](../../workflows/sdlc/verification.md) runs the full baseline over the whole delivery); **no new primitive, no fifth adapter port** (tool selection reuses `capability→tool`, the record is project context) — adapters only add the interview-section reference; adds the [quality-baseline](../patterns/quality-baseline.md) pattern, glossary terms, and a generic invariant-check; gives the ADR-016 gate a standing floor so quality can't silently erode and get caught too late
- 2026-08-14 — ADR-019 (loom setup approach for the Hermes harness) accepted; loom's **third** adapter and the **first resident-archetype** one. Reframes macro-PM as a peer **reactive-lifecycle** workflow (`workflows/macro-pm/`) beside the terminating SDLC — so Hermes **compiles the macro-PM seed**, not a self-contained SDLC (the first attempt's error). The adapter is **thin macro-only**: renders just the **resident PM agent** (a profile = `SOUL.md` + `cron`/`gateway` loop running [wayfinder macro mode](../../SKILLS/planning/wayfinder/SKILL.md)), **board wiring** (networked tracker over MCP, **not** single-host local kanban), **label provisioning** (`wayfinder:*`/`sdlc:*`), and the **altitude-seam translator** — and **dispatches SDLC runs down into a configured, headless-dispatchable per-invocation harness** (e.g. OpenCode) via **prose only** (no hardcoded `opencode --agent=` command — the micro harness is a setup choice, keeping content-only ADR-002); **invocation inverts** (resident PM = sole `front-door`, no local stage agents) recorded as a **port answer**, not an ADR-012 rewrite ([harness-archetypes](../patterns/harness-archetypes.md)); **cross-harness dispatch ⇒ the micro ledger is a shared on-disk, always-gitignored substrate** (Hermes memory can't cross a harness boundary; ephemeral coordination is never version-controlled) — this **amends ADR-014**'s committed-folder default → gitignored; **memory** is keyless-first (recommend local no-key **Holographic**, opt-in paid, degrade to built-in `MEMORY.md`/`USER.md`), **bounded as a forcing function**, relational-only (never project state), with the universal invariant in the protocol/glossary and the resident PM's operating discipline in its agent identity by reference; **amends ADR-018** ("not a peer workflow" → a peer *reactive-lifecycle* workflow, not a peer phase-pipeline). Deletes the first attempt's self-contained stage roster; adds `workflows/macro-pm/`, the two-lifecycle-kind framing in [workflows](../../workflows/index.md), and the [harness-archetypes](../patterns/harness-archetypes.md) pattern; SETUP/SPEC/validate gain Hermes+macro-PM conformance
- 2026-08-17 — ADR-020 (system-scoped QA as a coverage judgment over macro-PM) accepted. System-scoped QA needs **no new workflow**: construction is SDLC, charting is wayfinder, operation over time is the resident loop. The one genuinely-new thing is a coverage **judgment** — new skill [`derive-e2e-coverage`](../../SKILLS/verification/derive-e2e-coverage/SKILL.md): given a shipped feature's **user-perspective success criteria** (read from closed `sdlc:done` leaves, not the map, not the code), decide **which e2e scenarios must guard it**, emitting scenario specs (schema harvested from the retired qa-witness) as **buildable leaves**. Coverage is **folded into the effort map's destination** ("built AND guarded by passing e2e in the standing suite") so wayfinder's existing completion enforces it — **no new gate primitive**; **conditional** on the **behavioral-artifact test** (surfaceless efforts owe nothing). Authoring is **1:1** per feature; the **suite** is the system-scoped asset that accretes and re-runs. **E2E execution stays in CI** at deterministic points (staging/pre-prod) — the resident agent triggers/reacts, never executes (altitude boundary). A **regression seeds a fresh terminating map** (destination "restore green", triage as first ticket) — **seed, not chart** (mechanical destination, deferred judgment, same AFK map-creation as `needs-recharter` but a net-new root); it is a **monitor→board event**, **not** the `sdlc:*` fold-back. The verification **iron law** ("no completion claim without fresh evidence") is **promoted from a skill to the [verification-culture](../principles/verification-culture.md) principle** (peer to commit-often/architecture-first; precedent ADR-016); [`verification-before-completion`](../../SKILLS/verification/verification-before-completion/SKILL.md) slimmed to the evidence-gathering **procedure**; **`qa-witness-protocol` deleted** (pre-loom team/Prometheus/Sisyphus debris, schema harvested first). Re-wires verification index + SDLC verification phase + contract primitives; skill count holds at 37; validate.sh passes. Wayfinder/macro-PM wiring of the regression-seed rule + coverage-in-destination discipline deferred to a follow-up.
- 2026-08-17 — ADR-021 (Shaping is a read-only research orchestrator) accepted. Closes a leaky seam: Shaping's skills (`research`, `grill-with-docs`, the spike hatch) already dispatch subagents, but its capability set withheld `delegate` — so it **grants read-only `delegate`** (keeps `edit` withheld; `persist` scoped to the ledger), becoming a **read-only Dispatcher** that routes recon/research to the cheap `explore` Utility tier and spikes to `quick`/`deep` — the expensive Communicator context stays lean. Mirrors **Arbor**'s (arXiv 2606.11926) Coordinator/Executor split. **Amends ADR-008** (Shaping is a second, read-only dispatcher, not just the Orchestrator) and clarifies **ADR-012** (being a Dispatcher is orthogonal to invocation surface — Shaping is the one stage agent that is both `front-door` and Dispatcher). Fixes the **OpenCode `explore` cost gap**: always emit `.opencode/agents/explore.md` with the **Utility** archetype `model:` rather than reusing the bare built-in on its default model. Folds in two Arbor mechanisms minimally — **distilled evidence, not raw context** (`research` + `grill-with-docs`) and **prior-art-before-spike** (the spike hatch); defers the Idea-Tree backpropagation + budget steering. **Amends ADR-014**: drops the opt-in **OMO** model-tiering layer (inline `model:` already gives per-role tiering — one way, not two); deletes `adapters/opencode/references/omo.md` and the OMO interview/write/verify branches. Touches `contract/primitives.md` (Shaping cap set + orchestrator framing), both adapters' `STAGES.md`/`MAPPING.md`, opencode `setup.md`/`interview.md`/`write-format.md`/`verify.md`, `wiki/environments/opencode.md`, glossary Dispatcher, SPEC, SETUP.
