# ADR Log

- 2026-07-07 — v0.1 initial ADR-001 (adapter pattern) proposed
- 2026-07-14 — ADR-002 (workflows are prose-first adapter seeds) accepted
- 2026-07-14 — ADR-003 (architecture-first ordering) accepted
- 2026-07-20 — ADR-004 (loom setup approach for the Mirai harness) accepted; setup skill, 4-layer model, two-tier stage delivery, per-agent model matching
- 2026-07-21 — ADR-005 (harness-agnostic setup entrypoint + universal setup contract) accepted; reframes ADR-004 as the first adapter; setup/update run via SETUP.md read remotely, no command surface
- 2026-07-24 — ADR-006 (capability-based role discipline) accepted; roles are scoped capability sets, enforced by withholding (no-`edit` as a forcing function); generic capabilities the adapter maps to harness tool names and tolerates deviation
- 2026-07-24 — ADR-007 (optional documentation-lookup capability) accepted; tool-agnostic `docs-lookup`, off by default, interview-gated (Context7/MCP = current impl)
- 2026-07-24 — ADR-008 (Delivery dispatchers delegate execution and verification) accepted; Delivery splits into Planner + Orchestrator dispatchers; execution → `quick`/`deep`, verification → the reusable `verifier` utility; retires the single `delivery.agent.md`
- 2026-07-27 — ADR-009 (Frontend as a domain-specialized utility agent) accepted; adds the `frontend` dev/debug agent (first domain-specialized utility, wires 6 skills incl. `frontend-runtime-debugging`), delegates pixel-looking to the unchanged `visual-qa` isolation seam, rosters both `frontend` + `visual-qa` in the Mirai adapter, and factors the shared browser-drive contract into `wiki/patterns/browser-capture.md`
- 2026-07-30 — ADR-010 (keyless-by-default recommendations) accepted; generalizes ADR-007 from `docs-lookup` to all API-key tools: skills name capabilities not tools, API-key/account tools stay opt-in, graceful degradation on keyless substrate is mandatory, keyless-local tools (Playwright/Chrome DevTools) may remain defaults; adopts the [keyless-by-default](../principles/keyless-by-default.md) principle
- 2026-07-30 — ADR-011 (Seam Artifact Protocol) accepted; consolidates the three shallow context-movers (`handoff`, `session-bootstrap`, `dispatch-context`) behind one deep contract — a namespaced, manifest-indexed ledger with produce@exit / discover@entry obligations mandatory at the two stage seams; adds glossary terms (Stage, Seam artifact, Ledger, Communication protocol document), phase-gate updates, and Mirai adapter wiring (interview table 4d, `handoff.instructions.md` template, `handoffs:`/`persist` on stage agents); grounds [seam-artifact-protocol](../patterns/seam-artifact-protocol.md)
- 2026-07-31 — ADR-012 (Invocation surface is a role facet) accepted; names a closed `front-door | dispatched` vocabulary parallel to the capability set (ADR-006) — stage agents are `front-door` (`user-invocable:true` + `disable-model-invocation:true`; human/handoff-entered, not subagent-pulled), all utilities are `dispatched` (`user-invocable:false`; picker-hidden, dispatcher-only); adapter maps each surface to the Mirai flag pair; extends [role-scoped-capabilities](../patterns/role-scoped-capabilities.md), adds the **Invocation surface** glossary term, parametrizes `role.agent.md.template`, and leaves an autopilot forward-pointer (handoff `send:true` = a separate future effort)
- 2026-07-31 — ADR-013 (Shared adapter-contract core) accepted; records the #7 interface design and extends ADR-005 by defining the setup contract's shared body — a **prose contract of named port-obligations** (Design B) chosen over a filled-in template pack (Design A) because templates are harness detail the SPEC forbids in shared docs; core lives in a **new top-level `contract/`** dir (not under `adapters/`, not in `workflows/`) with `index.md` + `PORTS.md`; PROVIDES the generic content (5-step contract, init/update, 6 primitives + rosters/capability-sets/interview questions/invariant-checks), an adapter MUST SUPPLY **four named obligations** (`capability→tool`, `archetype→model`, `seam-obligation→wiring` + a `primitive→file` manifest) as prose tables; consumption = **reference, never copy** (setup.md goes thin); `SETUP.md` gains a Step-2 pointer and SPEC conformance gains one bullet; design-only — the migration is the foundation-build ticket (#9)
