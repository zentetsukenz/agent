# Naming — why Jacquard

*As of 2026-09-24.* Part of the [research](index.md) base; not a pillar. This page tracks names held
by live projects, so it goes stale like any landscape page. Re-check it before the repository-wide
rename.

Jacquard was chosen on 2026-09-24. The Jacquard loom (1804) moved the pattern from the weaver's head
onto punched cards the machine read, while a weaver still worked the loom — the vision in one
machine — and is an ancestor of programmable computing.

Rejected because live projects already hold the name in this space: **Centaur**
([paradigmxyz/centaur](https://github.com/paradigmxyz/centaur), agent infrastructure),
**Yoke** ([rp-exp/yoke](https://github.com/rp-exp/yoke), drives coding-agent harnesses),
**Heddle** ([getheddle/heddle](https://github.com/getheddle/heddle), multi-LLM orchestration),
**Bottega** ([vdaubry/bottega](https://github.com/vdaubry/bottega), always-on coding-agent
orchestration). Also taken: Warp, Mise, Crew, Rudder, Helm/Tiller, Forge, Smithy.

These were web and GitHub searches, **not a trademark search**. Check trademark registers, the GitHub
organisation, and npm/PyPI before the repository-wide rename.
