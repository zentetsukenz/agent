# Framework Log

- 2026-08-19 — **Added a spec-fidelity evidence category to verification (issue [#14](https://github.com/zentetsukenz/agent/issues/14), ADR-024).** Verification checked **correctness** but not **spec fidelity** — whether a PR that "closes #X" matches #X's acceptance criteria — so spec-vs-implementation deltas slipped the gate and surfaced only as manual follow-ups (affiliate-project #34 spec regex `^[a-z0-9_-]{1,64}$` vs PR #59's `^[A-Za-z0-9_-]+$`: a missing length cap and a pragmatically-correct-but-un-reconciled uppercase class). Fixed by adding spec fidelity as an **evidence category** the existing Verifier returns and the existing dispatcher routes on — **no new agent, primitive, or port**. When the artifact closes a ticket, resolve that ticket's acceptance criteria via the [Issue Tracker](wiki/environments/issue-tracker.md) env doc and report each as **matches / deviates / not-addressed**; a **deviation is evidence handed back to the dispatcher/human to judge intent, never an auto-failure** (auto-failing would reject pragmatically-correct code for literalism — matches the ADR-008 report/decide split). Placement split along loom's **skill-vs-tracker seam**: `SKILLS/verification/verification-before-completion/SKILL.md` phase 4 gains a tracker-agnostic spec-fidelity dimension (fetch mechanism resolved via the env doc, not hardcoded `gh`) + a Related link; `contract/primitives.md` names spec fidelity in the Verifier's purpose (per-adapter `STAGES.md` inherits it); `workflows/sdlc/verification.md` §5/§6 record the closing-ticket criteria as an existing criteria source (not a newly invented one) + a spec-fidelity report section. New immutable **ADR-024** (extends ADR-008 + verification-culture). Registered in `wiki/adr/{index,log}.md`, CHANGELOG. `scripts/validate.sh` passes
- 2026-08-18 — **Gave the `explore` utility a read-only shell (issue [#12](https://github.com/zentetsukenz/agent/issues/12), ADR-023).** `explore`'s capability set was `read`, `search` only — **no `shell`** — so the cheap Utility that ADR-021 routes recon to could not run `gh`/`git` reads or project read commands (`mix test`, `cat`, `ls`), bouncing the work back to the expensive Shaping agent and defeating the delegation contract. Fixed: `contract/primitives.md` gives `explore` **`read`, `search`, `shell`** (`edit`/`delegate`/`persist` stay withheld — the read-only line is the **withheld `edit`**, not the absent shell; mirrors the `verifier` + `visual-qa` `shell`+no-`edit` precedent). Render: OpenCode `permission: { edit: deny, bash: allow }` on the emitted `.opencode/agents/explore.md` (`adapters/opencode/STAGES.md` + `references/verify.md`); `adapters/mirai/STAGES.md` inherits via the generic contract (lists `execute`, `edit` unlisted). **No new port, no new primitive.** New immutable **ADR-023** (extends ADR-021/006; supersedes ADR-021's "`read`+`search` only" render note, ADR-021 body unchanged). Registered in `wiki/adr/{index,log}.md`, CHANGELOG. `scripts/validate.sh` passes
- 2026-08-18 — **Made OpenCode's `.loom` seam local-only and blanket-gitignored (issue [#11](https://github.com/zentetsukenz/agent/issues/11), amends ADR-014).** The 2026-08-14 "Option A" amendment had gitignored the *ledger artifacts* but kept the **protocol document** (`.loom/handoffs/protocol.md`) and **manifest** (`.loom/handoffs/index.md`) committed/tracked via a *selective* ignore (`.loom/handoffs/*/`) — so `update` against a project that blanket-ignored `.loom` proposed replacing the blanket rule with selective ones. Fixed: `.loom` is now a **purely local context-passing substrate** — setup seeds a **blanket `.loom/**` ignore** (protocol document, manifest, and artifacts all included), **no `.loom` path is required to be tracked or committed**, and `update` **preserves** an existing blanket ignore rather than proposing selective rules. **Removed the opt-in to commit the ledger for reviewable diffs** — durable/reviewable Macro-PM artifacts use the reachable orphan-ref substrate (ADR-022) instead. Aligned across `SPEC.md`, `adapters/opencode/{setup.md,MAPPING.md,STAGES.md,references/verify.md,references/write-format.md,assets/templates/handoff.md.template}`, the generic `contract/interview.md` §4d, and `wiki/adr/adr-014-loom-opencode-setup.md` (new 2026-08-18 amendment + Decision/Consequences/Alternatives wording).
