## Key Decisions

### Framework Clarification: Skills vs Knowledge

**Skills** (SKILLS/):

- Procedural judgment patterns
- Contain workflow/decision points
- Have "when to use" triggers
- Teach judgment (when/why, not just what)
- Examples: verification.md, checkpoint.md, task-sizing.md

**Knowledge** (docs/):

- Reference material and examples
- Declarative information
- Lookup/copy-paste documentation
- No procedural flow
- Examples: prisma-patterns.md, backend-patterns.md, database-schema.md

### Principle Added to Wisdom

Added to docs/wisdom.md → "On Knowledge":
> **Knowledge vs Skills distinction** — Knowledge is reference material (patterns, examples, schemas); Skills are procedures (workflows, when/why, decision points). If it's declarative and serves as lookup documentation, it belongs in docs/. If it has procedural flow and teaches judgment, it belongs in SKILLS/.
